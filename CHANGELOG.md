# Changelog

### Added

- **Initial release** — forked from [digital-chip-design-agents](https://github.com/chuanseng-ng/digital-chip-design-agents) v1.3.0

- **Full memory system**: two-tier persistent knowledge (experiences.jsonl + knowledge.md) with distillation and semantic search
- **Multi-IDE installer**: supports Claude Code, GitHub Copilot, Gemini, OpenCode, and OpenAI Codex CLI
